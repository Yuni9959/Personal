## 설계 원칙

1. **원본 답 기억 방지:** 원본의 그림과 수치를 그대로 재사용하지 않고, 동일한 인지 연산만 유지했습니다.
2. **이중 속성 확인:** 개수와 방향, 색과 모양처럼 두 규칙을 동시에 요구하는 문제는 오답 보기도 한 속성만 맞도록 설계했습니다.
3. **최종 선택 오류 교정:** 설명과 `trap` 필드를 통해 ‘답을 알아냈지만 다른 보기를 누르는 실수’를 반복적으로 경고합니다.
4. **난이도 상승:** 같은 유형의 1번은 규칙 하나, 5번은 복합 규칙·더 많은 요소·긴 작업기억을 요구하도록 구성했습니다.
5. **SVG 우선:** 정적 이미지 대신 SVG 문자열을 사용해 고해상도 화면과 오프라인 환경에서 선명하게 표시합니다.
