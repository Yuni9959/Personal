## 소스 범위와 폐기 정책

- 기초: T01~T18, T20~T25의 01~05번, 총 120문항
- 심화: 같은 24개 유형의 06~15번 중 활성 232문항
- 신규 300: 같은 24개 유형의 16~27번과 T26 01~12번
- Mensa Norway 기반 신규 350: S01~S35의 01~10번
- 폐기 유형: T19 15문항 전체
- 중복 폐기: T03 3문항, T08 1문항, T18 4문항

Mensa Norway 패키지의 `mkat-merged-650-v1.json`에 포함된 기존 300문항은
현재 은행의 부분집합이므로 병합에 사용하지 않습니다. 신규 전용 350문항을
현재 652문항과 교차 검사했으며 ID, 동일 자극, 동일 보기 묶음과 완전 시각
중복은 0건입니다.

소스별 활성 문항 수와 폐기 사유는 `question-bank.json`의
`sourcePackages`, `retiredTypes`, `retiredQuestions`에 기록합니다.

## 설계 원칙

1. **원본 답 기억 방지:** 공식 시험 원문을 복제하지 않고 동일한 추론 연산을 사용하는 독자 문항만 활성화합니다.
2. **이중 속성 확인:** 개수와 방향, 색과 모양처럼 두 규칙을 동시에 요구하는 문제의 오답은 한 속성만 맞도록 설계합니다.
3. **최종 선택 오류 교정:** `trap`, 오류 태그, 선택지별 피드백으로 규칙은 찾았지만 보기를 잘못 고르는 실수를 구분합니다.
4. **난이도 보존과 정규화:** 제작자 난이도는 보존하고 앱 통계에는 공통 1~5 런타임 난이도를 사용합니다.
5. **SVG 우선:** 정적 SVG를 사용해 고해상도 화면과 오프라인 환경에서도 선명하게 표시합니다.
