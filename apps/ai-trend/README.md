# AI Trend

Personal Tap의 한국어 AI 탐색 탭. `./apps/ai-trend/`에서 GitHub Pages 발행본을 읽는다.
클라우드 수집과 PC의 한국어 심층 생성은 별도 단계다.

- GitHub Trending의 오늘 증가 별과 최근 45일 생성된 `llm` 저장소를 분리한다.
  신규 저장소 정렬은 누적 별 기준이며 첫 수집에 성장량을 만들어내지 않는다.
  이후 수집은 직전 수집 대비 변화량을 명시한다.
- Hugging Face trendingScore 모델, OpenAI·Google AI·Hugging Face 공식 RSS를
  확인한다. 뉴스는 최근 7일이며 미래 항목과 위험 URL을 제외한다.
- 최대 프로젝트 6·뉴스 5·모델 3개. 원문 URL로 중복 제거하고 뉴스는 출처를
  순환한다. 일부 수집 실패는 출처 상태에 표시한다. 3개 미만 또는 분류가
  2개 미만이면 발행을 거부해 직전 파일을 보존한다.
- 프로젝트명은 원어로 유지하고, 설명은 자연스러운 한국어로 재서술한다. 카드뉴스는
  무엇인가 → 제작자의 설명 → 활용 예시 → 평가와 반응 → 도입 조건의 5장이다.
  각 장에 실제 조사 근거 링크를 제공한다. 제작자 주장·독립 반응·추정 활용을 구분한다.
  독립 평가·비용·메모리 등이 없으면 미확인으로 명시한다. 인기도는 품질 평가가 아니다.
- 분야는 고정 목록 대신 내용에 맞는 새 한국어 이름을 허용한다. 카드 상단 배지와
  발행본에서 자동 생성한 분야 필터에 표시한다.
- 검색·분야/출처 분류·관심 항목 저장·5장 독서·방향키·스와이프·근거 링크를 제공한다.
  저장은 기기 localStorage의 ID 목록이고 발행일 선택으로 과거 항목을 볼 수 있다.
  archive는 최신 30일만 유지한다. 기록과 원문을 가져올 때 저장소 코드를 실행하지 않는다.
- PWA는 최신 발행본과 앱 자산을 보관한다. nonce를 제거한 키로 network-first
  처리하므로 오프라인에서도 보관된 날짜를 명시하고 읽을 수 있다. fetch 실패 시
  화면의 발행본/검증된 로컬 보관본을 유지한다. 지난 발행본을 오늘로 바꾸지 않는다.

`npm run collect:ai-trend`로 수동 수집한다. 선택적으로 `GH_TOKEN`을 환경에
전달하면 GitHub API의 인증 호출 한도를 사용한다. 토큰을 데이터나 로그에 남기지
않는다. 실제 최신 데이터는 `data/latest.json`, 날짜 목록은 `data/index.json`,
과거 발행본은 `data/archive/YYYY-MM-DD.json`에 있다.

`daily-briefing.yml`은 05:17·11:17·17:17·23:17 UTC, 즉 **02:17·08:17·14:17·20:17 KST**에
하루 4회, 6시간 간격 예약과 수동 실행을 지원한다. 기존 08:17 수집 시각을 유지한다.
같은 날 재수집하면 해당 날짜의 발행본을 최신 값으로 교체하며 화면에 실제 수집시각을 표시한다.
AI와 주간 Volatility 수집을 각각 실행하고 전체 검증 후 생성 데이터만 게시한다.
직후 재사용 Pages workflow로 배포한다. 예약 지연이나 전체 수집 실패 시 화면에
직전 발행일을 표시한다. 외부 메시지·이메일·푸시 알림을 보내는 기능은 없다.

## 한국어 심층 생성 운영

이 PC의 `Personal Tap AI Trend Research` 작업이 매일 **02:35·08:35·14:35·20:35 KST**에
실행한다. PC가 켜져 있고 해당 Windows 사용자가 로그인한 동안 기존 Codex 인증을 사용한다.
놓친 실행은 사용 가능 시 시작한다. PC 종료·로그아웃·인증 만료·이용 한도·원문 차단 시 새
요약은 지연될 수 있다. 기존 검증 한글을 유지하며 카드별 검토 시각·8시간 초과 재검토
대기를 표시한다. 클라우드 수집이 새 한글 심층 요약까지 생성하는 구성은 아니다.

프로젝트 README·라이선스·개발 상태·공개 이슈, 정확한 저장소명과 일치하는 Hacker News
댓글, 모델 README·메타데이터·공개 토론, 뉴스 원문을 조사한다. 소수 이슈를 사용자 전체
평가로 확대하지 않으며, 닫힌 이슈가 수정 배포를 보증하지 않는다. 외부 저장소 코드는 실행하지 않는다.

`codex exec`의 구조화 출력으로 텍스트를 생성한다. 빈 임시 폴더에서 사용자 설정·프로젝트
지침을 로드하지 않고 셸·편집·검색·다중 에이전트·앱을 끈다. 외부 자료의 지시는 무시하며
모델이 만든 URL 대신 실제 근거 ID를 검증한다. 한글·5장·본문 길이·근거 ID·HTTPS URL을
검증한 결과만 게시한다. AI 요약은 오역·누락 가능성이 있으므로 근거 링크를 함께 제공한다.
ChatGPT/Codex 이용 한도를 사용하며 새 API 키나 유료 서비스를 발급하지 않는다. 로컬
인증 파일을 업로드하지 않는다. 다른 npm 설치는 `AI_TREND_CODEX_JS`로 JS 진입점을 지정한다.

`wscript.exe //B //Nologo` → 숨김 VBS → Python → Node로 창 없이 실행한다. 중복 실행
방지·2시간 제한·실제 종료코드·최근 30회 로그를 유지한다. `origin/main`의 임시 worktree에서
`apps/ai-trend/data/`만 커밋·푸시하고 Pages 배포를 요청한다. 사용 중인 소스 변경은 건드리지
않는다. Pages는 전체 릴리스 검증 후 공개한다. 충돌은 덮어쓰지 않고 로그와 복구본을 남긴다.

- `npm run research:ai-trend`: 조사·생성·로컬 발행 파일 갱신.
- `powershell -NoProfile -File apps/ai-trend/tools/register-research-task.ps1`: 예약 등록.
- `python apps/ai-trend/tools/research-background.py`: 격리 생성·데이터 게시.
- `data/analyses.json`: URL별 검증 한글·근거 링크·검토 시각 캐시. 원문 전체·인증·로컬 경로 제외.
- `%LOCALAPPDATA%\PersonalTap\ai-trend\research-*.log`: 운영 로그.
- 예약 제거: `Unregister-ScheduledTask -TaskName 'Personal Tap AI Trend Research' -Confirm:$false`.

새 항목의 생성 실패 시 영어 임시 카드로 대체하지 않고 대기 수를 표시한다. 카드 3개 미만
또는 종류 2개 미만이면 마지막 검증 한글 발행본의 날짜·본문을 보존한다. 과거 schema 1의
3장 보관본은 이전 형식으로 표시하고, 최신 schema 2에 5장 한글·근거 검증을 적용한다.
예약 실행은 `gh auth token`을 메모리로 읽어 수집에만 전달하고 모델 호출에서 제거한다.
토큰은 명령행·로그·데이터·Git에 남기지 않는다.

검증: `npm run test:ai-trend`, 전체 `npm run test:release`.
